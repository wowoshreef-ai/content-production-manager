# مدير إنتاج المحتوى (Content Production Manager)

نسخة مطوّرة ومستقلة تمامًا من "جدول الإنتاج الأسبوعي" لقنوات **القيادي · رائج · عرب جيمرز · سائح**.
المشروع ده **مفيهوش أي ربط** بالموقع القديم أو بياناته أو استضافته.

> ℹ️ أول مرة بيتحمّل جدول شبه موقعك القديم: 4 قنوات (⚡ القيادي · 🔥 رائج · 🎮 عرب جيمرز · ✈️ سائح) × 6 أيام (الجمعة → الأربعاء) × 4 مهام = 24 مهمة، والهدف 18 والباقي بونص. ده اتبنى من الـ HTML اللي بعتّه، ومش منقول من قاعدة بيانات الموقع القديم (ومفيش أي اتصال بيه). عدّل أي حاجة من ⚙️ الإعدادات.

## الميزات

| الطلب | اللي اتعمل |
|---|---|
| مهام أسبوعية ثابتة قابلة للتعديل | قائمة مهام ثابتة (قناة + اسم + يوم + "فيديو؟") بتتطبق على كل أسبوع جديد تلقائيًا. تعديلها من الإعدادات |
| تعديل أيام الشغل | اختيار أيام الشغل ويوم بداية الأسبوع. التذكير بيتبعت في أيام الشغل بس |
| النسبة: 18 فيديو = أسبوع كامل | الهدف قابل للتعديل (18 افتراضيًا). النسبة بتثبت على 100% والزيادة بتتعدّ **بونص** (مثلًا 20 فيديو = 100% + 2 بونص) |
| "تم الرفع" | صندوق جنب "اكتمل" بيسجّل وقت الرفع. تعليمه بيعلّم الفيديو "اكتمل" كمان، وإلغاء "اكتمل" بيلغي الرفع |
| خانة ملاحظات وروابط جنب السكريبت | الروابط بتتحوّل لروابط قابلة للضغط تحت الخانة |
| السكريبت بيتمدد تلقائي ومن غير شريط طلوع ونزول | الخانة بتكبر مع الكتابة (`overflow: hidden`) |
| كتابة العناوين تلقائيًا | زر "ولّد العناوين": بيبعت السكريبت وأسلوب القناة للـ AI ويرجّع 5 عناوين، وتختار واحد. Claude أو Gemini أو OpenAI |
| الثامبنيل | زر "ولّد الصورة": بيولّدها بـ Gemini API وتتحفظ وتتحمّل. وزر تاني بيفتح Google Flow وينسخ البرومبت |
| تذكير يومي على الكمبيوتر | إشعار (Web Push) بالمهام المتأخرة وميعاد النهاردة، مرة واحدة في اليوم في الميعاد اللي تحدده |
| الصفحات الرئيسية | واجهة Creator OS بأربع صفحات: النهارده، الأسبوع، السجل والتحليلات، والسكريبتات. الإعدادات تظهر كصفحة كاملة، مع الاحتفاظ بملخص الإنجاز والرفع وبطاقات القنوات. |
| لون اليوم المكتمل | لما كل مهام يوم تخلص اليوم كله بيتلوّن أخضر ويظهر عليه "✓ اليوم اكتمل" وعدّاد (مثلًا 3/3) |
| معرفة إن السكريبت اتكتب من برا | علامة "✅ تم كتابة السكريبت" بتظهر لوحدها على المهمة أول ما تكتب أي حاجة في خانة السكريبت (من غير ما تضغط أي زرار)، وعدّاد السكريبتات المكتوبة فوق |
| صفحة السكريبتات (`#/scripts`) | مربوطة بالجدول بزر في الهيدر. تبويب لكل يوم (بعدّاد جاهز/الكل) وفيه سكريبتات مهامه مفتوحة للكتابة، وتنقل أي مهمة ليوم تاني من القائمة. فيها **مخزن سكريبتات**: اكتب سكريبتات الأول وبعدين "وزّع" كل واحد على مهمة (بيتنقل كمسودة وبيتشال من المخزن، وبيسألك قبل ما يستبدل سكريبت موجود) |

## التشغيل

**المطلوب:** Node.js **22.13 أو أحدث** (https://nodejs.org).

```bash
cd content-production-manager
npm install
cp .env.example .env      # على ويندوز: copy .env.example .env
# افتح .env واكتب RESET_PASSWORD ومفاتيح الـ AI اللي عايزها
npm start
```

افتح http://localhost:3000

لتشغيل الاختبارات: `npm test`

## ⚠️ تحذيران مهمين قبل ما تنشره على استضافة

1. **حفظ البيانات:** البيانات في ملفات داخل `DATA_DIR` (قاعدة SQLite + الصور + مفاتيح الإشعارات). الاستضافات المجانية (زي Render المجاني) **بتمسح الملفات** مع كل إعادة تشغيل أو نشر. لازم **قرص دائم (Persistent Disk)** أو تشغّله على جهازك/VPS. من غير كده هتضيع المهام والسكريبتات.
2. **التذكير محتاج السيرفر شغال:** الإشعار بيتبعت من السيرفر. لو الاستضافة بتنام بعد فترة خمول (Render المجاني بيعمل كده) التذكير مش هيوصل. على جهازك: السيرفر لازم يكون شغال في وقت التذكير.

لو منشور على الإنترنت: ضيف `BASIC_AUTH_USER` و `BASIC_AUTH_PASS` في `.env`، وإلا أي حد معاه الرابط يقدر يستهلك رصيد الـ AI بتاعك. وضبط `HOST=0.0.0.0` (Render بيعملها لوحده).

## ربط الذكاء الاصطناعي

المفاتيح بتتحط في `.env` على السيرفر بس (مش بتظهر في الواجهة). كل واحد منهم اختياري.

| الغرض | المتغيّر | من فين |
|---|---|---|
| العناوين (Claude) | `ANTHROPIC_API_KEY` | https://console.anthropic.com |
| العناوين (Gemini) | `GEMINI_API_KEY` | https://aistudio.google.com |
| العناوين (OpenAI) | `OPENAI_API_KEY` | https://platform.openai.com |
| الصور المصغرة | `GEMINI_API_KEY` (نفس مفتاح Gemini) | https://aistudio.google.com |

بعد ما تعدّل `.env` أعد تشغيل السيرفر. أسماء الموديلات قابلة للتغيير من `.env` (شوف `.env.example`).

### بخصوص Google Flow
Google Flow أداة على الويب **ومفيش API رسمي** ليها (على حد علمي وقت كتابة المشروع)، فالموقع **مبيقدرش يشغّلها لوحده**. اللي اتعمل بدل كده:
- توليد الصورة المصغرة مباشرة من **Gemini API** (موديلات صور Google)، من غير ما تنقل أي برومبت بإيدك.
- زر "افتح Google Flow" بينسخ البرومبت ويفتح Flow لو عايز تكمّل منه.

### ⚠️ إيه اللي اتجرّب وإيه لأ
- كل الوظائف اتجرّبت (اختبارات آلية + متصفح حقيقي) **بخدمات AI وهمية**، يعني شكل الطلبات والردود واتحقق منه، لكن **مفيش اتصال حقيقي بخدمات Claude/Gemini/OpenAI اتجرّب** لأن مفيش مفاتيح. لو موديل غيّر اسمه أو شكل الرد، عدّل `GEMINI_IMAGE_MODEL` / `ANTHROPIC_MODEL` في `.env`.
- وصول الإشعار الفعلي للمتصفح (Web Push) اتجرّب بإرسال وهمي. اختبره عندك: ⚙️ الإعدادات ← "فعّل الإشعارات" ← "جرّب التذكير دلوقتي".

## الإشعارات (التذكير اليومي)
1. افتح الموقع على **localhost أو HTTPS** (شرط من المتصفح).
2. دوس **🔔 فعّل الإشعارات** واسمح للمتصفح. (Chrome أو Edge)
3. ⚙️ الإعدادات: حدّد وقت التذكير وأيام الشغل، وجرّبه بزر "جرّب التذكير دلوقتي".

الإشعار بيوصل حتى لو تبويب الموقع مقفول (طالما المتصفح شغال والسيرفر شغال).
على ويندوز تأكد إن إشعارات Chrome/Edge مسموحة وإن وضع "عدم الإزعاج / Focus" مقفول.

## الأمان والبيئة
- `RESET_PASSWORD`: كلمة سر تصفير الأسبوع (الافتراضي `changeme` — غيّره). نسخة الـ HTML المستقلة باسورد التصفير فيها `2002` (نفس القديم) ومكتوب جوه الملف، فمش حماية حقيقية.
- مفاتيح الإشعارات (VAPID) بتتولّد تلقائي في `data/vapid.json`. على استضافة من غير قرص دائم حطها في `.env` (الأمر: `npx web-push generate-vapid-keys`).
- `SEED_DEMO=false` لو مش عايز الجدول الجاهز يتحمّل أول مرة.

## هيكل المشروع
```
server/   index.js (التشغيل) · app.js (الـ API) · store.js (SQLite) · ai.js (العناوين والصور)
          progress.js (النسبة والبونص) · scheduler.js + push.js (التذكير) · dates.js · seed.js (الجدول الافتراضي)
public/   index.html · app.js · styles.css · theme.css (الألوان والخطوط) · sw.js (الإشعارات)
test/     اختبارات الوحدات والـ API
```

### تغيير التصميم
كل الألوان والخطوط في `public/theme.css`. التصميم الحالي داكن بألوان هادية مريحة للعين (رمادي مزرق، نص أبيض مكسور، لون دافي لتحديد اليوم الحالي). غيّر القيم في الملف ده لتغيير الألوان.
