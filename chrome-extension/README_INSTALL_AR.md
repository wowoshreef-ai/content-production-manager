# إضافة مدير إنتاج المحتوى لـ Chrome

الإضافة تضيف زرًا إلى شريط Chrome يفتح لوحة الموقع مباشرة. لا تطلب صلاحيات قراءة علامات التبويب أو بيانات التصفح.

## التثبيت على Windows

1. نزّل ملف `creator-os-chrome-extension.zip` وفك ضغطه.
2. افتح `chrome://extensions` في Chrome.
3. فعّل **وضع المطوّر** من أعلى الصفحة.
4. اضغط **تحميل إضافة غير مُجمّعة** واختر مجلد `chrome-extension` بعد فك الضغط.
5. من قائمة الإضافات، ثبّت «مدير إنتاج المحتوى» في شريط الأدوات.

اضغط أيقونة الإضافة ثم **فتح لوحة الإنتاج**. يحتاج الموقع إلى اتصال بالإنترنت.
